Accessibility

Development DEV-05

Detailed description

An accessible site can be used by everyone, including people with disabilities: blind or visually impaired people, deaf or hard-of-hearing people, people who cannot use a mouse, or who have difficulty concentrating or understanding. It also concerns temporary situations: an arm in a cast, a screen seen in bright sunlight, a noisy environment.

The international rules are called the WCAG (in France, the equivalent standard is the RGAA, mandatory for certain organizations). The basic good practices: add an alternative text to every image so that screen readers (software that reads the page aloud) can describe it, check contrast, allow everything to be done with a keyboard, caption videos, and link each form field to a clear label. Good news: these efforts also benefit search ranking and all users.

Examples of use cases

  • Adding alternative text to a product photo: “Silver ring set with a blue stone”.
  • Navigating your own site using only the Tab key: you quickly see what blocks.
  • Captioning a presentation video for deaf people and for those watching without sound.

Vocabulary to know

WCAG
The international web accessibility rules.
Screen reader
Software that reads a page’s content aloud.
Alternative text (alt attribute)
The description of an image intended for those who cannot see it.
