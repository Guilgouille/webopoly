Color Palette

Graphic Design DES-02

Detailed description

The palette is the set of 3 to 5 colors chosen to represent the brand and used everywhere, from the website to posters. Colors convey emotions: blue inspires trust, red energy, green nature and health, yellow optimism. These associations vary between cultures, however, so they should not be applied mechanically.

A well-built palette distinguishes several roles: a primary color (the one that carries the identity), a secondary color, an accent color (reserved for important elements, like action buttons) and neutrals (white, gray, black) for text and backgrounds. You must also watch the contrast between text and its background: accessibility rules ask for a ratio of at least 4.5 to 1 for regular text, so that everyone can read it. Finally, each color is recorded with a code: HEX or RGB for screens, CMYK for printing.

Examples of use cases

  • Choosing a dark blue as the primary color, an orange accent for the “Request a quote” buttons and grays for text.
  • Checking with an online tool that white text on a pale yellow background is unreadable, and replacing it.
  • A bank opts for a reassuring, sober blue, while an energy drink picks a vivid, dynamic red.

Vocabulary to know

HEX code
The code of an on-screen color, for example #1A73E8.
Contrast
The difference in brightness between text and its background.
Accent color
The color used sparingly to catch the eye.
