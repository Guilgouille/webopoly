HTML/CSS Integration

Development DEV-01

Detailed description

Integration means turning a mockup into a real web page that any browser can display. Two languages share the work. HTML describes the structure and content: headings, paragraphs, images, links, buttons, using tags. CSS describes the appearance: colors, sizes, margins, fonts, layout. To compare, HTML is the skeleton and walls of a house, CSS the paint and decoration.

A good integrator writes semantic HTML: they choose the tags that give meaning to the content (a real heading for a heading, a real list for a list, areas identified as the header, the menu or the main content). This is not just tidiness: it helps Google understand the page and helps screen readers read it. A browser simply reads text files: you write them in a code editor and inspect them with the browser’s developer tools (the F12 key).

Examples of use cases

  • Coding the home page drawn in Figma so that it displays in a browser.
  • Using a single main heading per page and well-ordered subheadings, for SEO as well as accessibility.
  • Using the browser’s inspector to find out why a button is shifted by a few pixels.

Vocabulary to know

Tag
A keyword between angle brackets, like <p> for a paragraph, that indicates the nature of a piece of content.
Semantic HTML
Tags chosen for their meaning, not only for their appearance.
Developer tools
The inspector built into the browser to examine and test a page.
