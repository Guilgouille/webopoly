Design System

UX/UI Design UX-08

Detailed description

A design system is a library of reusable components (buttons, form fields, cards, menus…) together with their usage rules: colors, spacing, fonts, tone of messages. You can see it as a box of Lego: standardized pieces that you assemble to build all the pages.

Its advantages are many. Consistency: the button is the same everywhere. Speed: you assemble instead of redrawing. Shared language: designers and developers talk about the same components. Maintenance: you change a button in one place and the change applies everywhere. One of the best-known public examples is Material Design, Google’s system. For a small team, we advise starting simple (colors, fonts, buttons) and then growing it project after project.

Examples of use cases

  • A primary button defined once and used identically on 50 pages.
  • A new designer assembles a page in a few hours thanks to the existing components.
  • A large company that runs several websites keeps a consistent look thanks to a shared design system.

Vocabulary to know

Component
A reusable interface element (button, field, card).
Design token
A named value (color, spacing) used everywhere.
Consistency
The fact that everything works and looks the same way.
