Back-end

Development DEV-08

Detailed description

The back-end is the invisible part of a site: the one the visitor never sees but without which nothing would work. It includes the server (a computer that answers requests), the application’s code and the database that stores information (accounts, orders, messages). The front-end, by contrast, is what is displayed in the browser. Imagine a restaurant: the dining room is the front-end, the kitchen is the back-end.

Take a quote request form. When the visitor clicks “Send”, the browser transmits the information to the server; the code checks that it is correct, saves it in the database, triggers an email, then sends back a response (“Thank you, your request has been recorded”). The back-end is written with languages like JavaScript (Node.js), PHP or Python, and uses databases such as PostgreSQL or MySQL. Golden rule: never trust data sent by a form and always check it on the server side.

Examples of use cases

  • Saving quote requests in a database and sending an email to the agency.
  • Handling account creation and user login.
  • Calculating a cart’s total on the server side, so that a visitor cannot change the price themselves.

Vocabulary to know

Server
A computer that receives requests and answers them.
Database
The place where information is stored and retrieved in an organized way.
API
A standardized way for two pieces of software (for example the front-end and the back-end) to talk to each other.
