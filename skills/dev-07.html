Security

Development DEV-07

Detailed description

Security means protecting the site and its users’ data against hacking, information theft and outages. Common threats are mundane: a password that is too simple, outdated software whose vulnerability is known to every hacker, a poorly protected form, a fake email that traps an administrator (phishing).

The basic protections are: HTTPS (the padlock in the address bar, which encrypts exchanges between the visitor and the site), regular updates, strong passwords combined with two-factor authentication, limited access rights (everyone accesses only what they need) and backups. Users’ passwords must never be stored in plain text. There is no absolute security: you reduce risks and prepare how to react. And a backup that has never been tested is not a real backup.

Examples of use cases

  • Updating the plugins of a WordPress site every month to fix known vulnerabilities.
  • Restoring a backup on a test site to check that it works.
  • Enabling two-factor authentication for all administrator accounts.

Vocabulary to know

HTTPS
The secure version of the web protocol, which encrypts exchanges.
Vulnerability
A weakness in software that a hacker can exploit.
Two-factor authentication
A second proof of identity, for example a code received on your phone.
