Responsive Design

Development DEV-02

Detailed description

A responsive site automatically adapts to the screen size: computer, tablet or smartphone. Today, most visits come from mobile, so a site that does not work well on a phone loses most of its visitors. Instead of building a separate site for each device, you create one whose elements rearrange themselves.

Technically, you use CSS rules that change depending on the screen width (media queries), flexible layout systems (flexbox and grid) and relative units (percentages rather than fixed pixels). The moments when the layout switches are called breakpoints. A few habits: plan touch areas big enough for a finger, text readable without zooming, and images that shrink with the screen.

Examples of use cases

  • A horizontal menu on a computer becomes a “burger” menu (three lines) on mobile.
  • Three columns side by side on a large screen stack one under the other on a phone.
  • Testing the site on a real phone, because shrinking the computer window does not reproduce everything (touch, speed…).

Vocabulary to know

Media query
A CSS rule that applies only to certain screen sizes.
Breakpoint
The width at which the layout changes.
Burger menu
The three-line icon that unfolds the menu on mobile.
